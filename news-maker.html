पहिल्यांदा: GitHub टोकन कसे बनवायचे
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: फक्त ClaimTak.in निवडा
  3. Permissions → Contents: Read and write
  4. Generate करून टोकन कॉपी करा आणि खाली टाका. ते फक्त या फोनमध्ये/ब्राउझरमध्ये सेव्ह राहते.
टोकन कोणालाही शेअर करू नका. गरज संपल्यावर GitHub वरून रद्द करता येते.
